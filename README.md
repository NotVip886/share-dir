# 局域网文件共享

基于 [Wails](https://wails.io/) 构建的局域网文件共享桌面应用，一键开启共享，同一局域网内的设备即可通过浏览器访问、上传和下载文件。

## 功能特性

- **一键共享** - 选择文件夹后点击开启，自动启动 HTTP 服务（端口 8765）
- **二维码访问** - 开启共享后自动生成二维码，手机扫码即可访问
- **文件浏览与下载** - 访客可通过网页浏览共享目录中的文件并下载
- **文件上传** - 访客可通过网页拖拽或选择文件上传到共享目录，支持多文件上传（最大 100MB）
- **消息板** - 内置实时消息板，共享者和访客可互相发送消息交流
- **拖拽上传** - 桌面端支持将文件直接拖拽到窗口上传
- **复制链接** - 一键复制共享地址到剪贴板
- **浏览器打开** - 快速在默认浏览器中打开共享页面

## 技术栈

- **后端**: Go + Wails v2
- **前端**: Vue 3 + Vite
- **Web 端**: 内嵌 HTML 页面，供局域网访客访问

## 构建

```bash
wails build
```

## 运行开发模式

```bash
wails dev
```
