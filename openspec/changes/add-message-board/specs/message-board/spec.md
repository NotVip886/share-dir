## ADDED Requirements

### Requirement: 消息发送与接收
系统应允许共享者和访问者发送和接收消息。

#### Scenario: 共享者发送消息
- **WHEN** 共享者在消息对话框输入内容并点击发送
- **THEN** 消息添加到消息列表，发送者标识为"共享者"

#### Scenario: 访问者发送消息
- **WHEN** 访问者在消息对话框输入内容并点击发送
- **THEN** 消息添加到消息列表，发送者标识为名字或IP

### Requirement: 消息列表展示
系统应展示所有消息，按时间倒序排列。

#### Scenario: 查看消息列表
- **WHEN** 用户打开消息对话框
- **THEN** 显示所有消息，每条消息包含发送者、内容、时间

#### Scenario: 消息数量限制
- **WHEN** 消息数量超过50条
- **THEN** 自动删除最早的消息

### Requirement: 访问者身份标识
系统应为访问者提供身份标识，默认使用内网IP。

#### Scenario: 默认使用IP标识
- **WHEN** 访问者未设置自定义名字
- **THEN** 发送消息时使用内网IP作为标识

#### Scenario: 自定义名字标识
- **WHEN** 访问者设置了自定义名字
- **THEN** 发送消息时使用名字作为标识，格式为"名字(IP)"

### Requirement: 消息轮询刷新
系统应定期刷新消息列表。

#### Scenario: 自动刷新消息
- **WHEN** 消息对话框打开或每3秒
- **THEN** 自动请求最新消息列表

### Requirement: 消息清空
系统应允许清空所有消息。

#### Scenario: 清空消息
- **WHEN** 用户点击清空按钮
- **THEN** 删除所有消息
